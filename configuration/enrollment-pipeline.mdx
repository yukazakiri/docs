---
title: "Enrollment pipeline and applicant automation"
description: "Configure the enrollment pipeline in KoAkademy and turn on automation that creates enrollment records and assigns subjects to new applicants."
---

The enrollment pipeline controls how an application moves from submission to confirmation, and the **Applicant Automation** settings let KoAkademy take care of repetitive registrar work the moment a student applies. Use these options to skip manual data entry for first-year intakes and to push new applicants straight into a complete enrollment record.

## Where to find these settings

Open the admin panel and go to **System Management** → **Enrollment Pipeline**. The **Applicant Automation** card appears alongside the pipeline step editor. Changes save with the rest of the pipeline configuration.

## Applicant automation toggles

Applicant automation is built around three switches. They are layered, so each option only becomes available after the one above it is on.

| Setting | What it does | Default |
|---|---|---|
| **Treat new applicants as 1st year automatically** | Marks every new applicant as a 1st year student so first-year-based policies apply. | On |
| **Auto-create Student Enrollment record** | Creates a `StudentEnrollment` record for the applicant using the active school year and semester. | Off |
| **Auto-assign available subjects/classes** | Adds first-year subjects for the applicant's course and places them into open class sections. | Off |

<Note>
  The toggles are dependent. If you turn off **Treat new applicants as 1st year automatically**, the other two switches turn off and become unavailable. If you turn off **Auto-create Student Enrollment record**, **Auto-assign available subjects/classes** turns off too.
</Note>

### Treat new applicants as 1st year automatically

Keep this on if your institution receives mostly first-year intakes and you want first-year curriculum logic to apply to every new applicant. Turn it off if applicants commonly enter at higher year levels and you prefer to set the year level manually before any automation runs.

### Auto-create Student Enrollment record

When this is on, submitting the new applicant form creates a `StudentEnrollment` record in the same database transaction as the student profile. The record uses:

- The current school year (from your academic settings).
- The current semester (from your academic settings).
- The course the applicant selected on the form.
- Year level **1** when first-year treatment is enabled.

Use this when you want applicants to appear in enrollment lists immediately, without a registrar having to create the record by hand.

### Auto-assign available subjects/classes

When this is on, KoAkademy looks up the first-year subjects for the applicant's course and current semester, then:

1. Adds each subject to the applicant's enrollment.
2. Finds an **open class section** for that subject — one whose `maximum_slots` is not yet reached — and enrolls the applicant in it.
3. Generates a tuition record based on the subject lecture and laboratory units.

Subjects without an open class section are still added to the enrollment record, but the applicant is not assigned to a class for them. A registrar can place the student in a section later.

<Tip>
  Pair this toggle with up-to-date class sections. If no sections exist for a subject in the current school year and semester, KoAkademy cannot place the applicant automatically.
</Tip>

## Recommended configurations

<CardGroup cols={2}>
  <Card title="Manual enrollment (default)" icon="hand">
    Leave **Auto-create Student Enrollment record** and **Auto-assign available subjects/classes** off. Applicants submit the form, then a registrar reviews and creates the enrollment record by hand.
  </Card>
  <Card title="Lightweight automation" icon="wand-magic-sparkles">
    Turn on **Auto-create Student Enrollment record** only. New applicants get an enrollment record automatically, but a registrar still picks subjects and class sections.
  </Card>
  <Card title="Full first-year automation" icon="bolt">
    Turn on all three switches. New applicants get an enrollment record, first-year subjects, class section placements, and a tuition record on submission.
  </Card>
</CardGroup>

## How to turn on full automation

<Steps>
  <Step title="Open the enrollment pipeline page">
    In the admin panel, go to **System Management** → **Enrollment Pipeline**.
  </Step>
  <Step title="Enable first-year treatment">
    Turn on **Treat new applicants as 1st year automatically**. The two automation switches become available.
  </Step>
  <Step title="Enable enrollment record creation">
    Turn on **Auto-create Student Enrollment record**. **Auto-assign available subjects/classes** unlocks.
  </Step>
  <Step title="Enable subject and class assignment">
    Turn on **Auto-assign available subjects/classes**.
  </Step>
  <Step title="Save the pipeline">
    Save the enrollment pipeline. The next applicant submission runs through the full automation flow.
  </Step>
</Steps>

<Warning>
  Automation runs only when an applicant submits the new student form. It does not retroactively create records for applicants who already exist.
</Warning>
