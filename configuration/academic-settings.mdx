Academic settings control what term your institution is currently operating in, when students can enroll, and which program types your school supports. Getting these settings right ensures that every student and faculty member sees the correct data as soon as they log in.

## Setting the active school year and semester

The active school year and semester you set in the admin panel act as the global default. When a new user logs in for the first time, they see data for this term automatically.

<Steps>
  <Step title="Open the admin panel">
    Log in to the admin panel and navigate to **Academic Settings**.
  </Step>
  <Step title="Select the active school year">
    Choose the school year from the dropdown. This becomes the default for all users who have not set a personal preference.
  </Step>
  <Step title="Select the active semester">
    Choose the current semester (for example, First Semester, Second Semester, or Summer). Save your changes.
  </Step>
</Steps>

<Note>
  Individual users can override the global default from their own profile settings. Their personal selection persists until they change it again.
</Note>

## Enrollment period control

The enrollment period setting determines when the online enrollment form is open to students. Outside of this window, students see a notice that enrollment is closed.

- **Open** — Students can access and submit the enrollment form.
- **Closed** — The enrollment form is hidden. Students can view their existing enrollment records but cannot submit new ones.

Set the enrollment period in **Academic Settings** under **Enrollment Window**. You can open or close enrollment manually at any time.

<Tip>
  Announce enrollment opening dates through the Announcements module so students are notified in advance.
</Tip>

## Income brackets for enrollment

The enrollment form asks new students to record their family income range. KoAkademy ships with two income basis modes — **Annual Income** and **Monthly Income** — each with its own list of brackets. Students choose the basis at enrollment and then pick either a single shared family bracket or separate ranges for the father and mother.

You can change the default basis and the bracket lists in `config/income_brackets.php`. Each bracket has a `min`, `max`, and a `label`. Use `{symbol}` in labels — KoAkademy replaces it with the currency symbol from your site settings at runtime.

```php config/income_brackets.php
return [
    'default_mode' => 'annual',
    'modes' => [
        'annual' => [
            'label' => 'Annual Income',
            'brackets' => [
                'below_250k' => [
                    'label' => '{symbol}250,000 and below',
                    'min' => 0,
                    'max' => 250_000,
                ],
                // ...add more brackets here
            ],
        ],
        'monthly' => [
            'label' => 'Monthly Income',
            'brackets' => [
                'below_10k' => [
                    'label' => 'Less than {symbol}10,000',
                    'min' => 0,
                    'max' => 9_999,
                ],
                // ...add more brackets here
            ],
        ],
    ],
];
```

| Key | Description |
| --- | --- |
| `default_mode` | The mode pre-selected on the enrollment form. Must match a key under `modes`. |
| `modes.<key>.label` | Display label for the basis option (for example, `Annual Income`). |
| `modes.<key>.brackets` | Ordered list of bracket options shown when this basis is selected. |

<Tip>
  Add new modes (such as a quarterly basis) by adding another entry under `modes`. Any mode you add automatically appears in the **Income Basis** dropdown on the enrollment form.
</Tip>

<Note>
  Each enrollment record stores the basis (`income_bracket_mode`), whether both parents share a bracket (`use_same_parent_income`), and the selected bracket keys (`family_income_bracket`, `father_income_bracket`, `mother_income_bracket`). Changing a bracket key in config does not retroactively update existing records.
</Note>

## Multi-school (organization) setup

If your institution has multiple campuses or schools, each can be configured as a separate **organization** in KoAkademy. Faculty and students assigned to more than one organization can switch between them without logging out.

<Steps>
  <Step title="Create organizations">
    In the admin panel, go to **Organizations** and add each campus or school as a separate entry.
  </Step>
  <Step title="Assign users">
    Assign students and faculty to the appropriate organizations. A user can belong to more than one.
  </Step>
  <Step title="Switch between organizations">
    Users with access to multiple organizations see an organization switcher in the portal navigation. Selecting a different organization reloads their data for that campus.
  </Step>
</Steps>

<Note>
  Each organization maintains its own active school year, semester, and enrollment period. Changes to one organization's academic settings do not affect other organizations.
</Note>
